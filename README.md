# MyCal

Sistema de controle alimentar desenvolvido para facilitar o acompanhamento de calorias, macronutrientes e organização de refeições diretamente pelo Telegram.

---

## Sobre o Projeto

O **MyCal** é um projeto backend desenvolvido em Python com integração ao Telegram, permitindo que o usuário registre alimentos, organize refeições e acompanhe sua ingestão diária de macronutrientes de forma prática.

O objetivo principal do projeto é transformar o processo de contagem de calorias e macros em algo rápido, acessível e automatizado, utilizando comandos diretamente em um bot do Telegram.

---

## Funcionalidades

### Alimentos
- Cadastro de alimentos
- Listagem de alimentos cadastrados
- Edição de alimentos
- Exclusão de alimentos

### Refeições
- Criação de múltiplas refeições
- Organização alimentar por refeição
- Associação de alimentos às refeições
- Controle de quantidade consumida

### Controle Nutricional
- Contagem automática de calorias
- Controle de proteínas
- Controle de carboidratos
- Controle de gorduras
- Comparação com metas diárias definidas pelo usuário

### Integração
- Bot integrado ao Telegram
- Comandos automatizados
- Respostas interativas via bot

---

## Tecnologias Utilizadas

- Python
- MySQL
- Telegram Bot API
